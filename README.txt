# Django---MultiRole---Marketplace
'Servixa' is a multi role service marketplace web application built using Django. It connects professional service providers including companies and independent freelancers.
many services like home maintainance, salon, technical services etc.. can be provided to required customers.
Role-Based access : distinct functionalities for Super Admins, Company Admins,company emplyers, Freelancers and customers.
AI-Enhanced Contents : integration with local LLM (ollama) to automate service descriptions and overview
Complete CRUD : full create, read, update, and delete operations for service 
Responsive UI : used HTML and Bootstrap

Project Setup Steps:
-> clone the repository ( git clone http [path of repository] )
-> create and activate  a virtual environment
-> install the required packages (pip install -r requirements.txt)
-> perform database migrations
-> Run the project ( py manage.py runserver)
